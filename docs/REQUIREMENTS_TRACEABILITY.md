## 2. Non-Goals Enforcement Verification

The following items are confirmed as excluded from all architectural specifications, migrations, and database tables:
- **No Multi-Tenancy:** Zero `tenant_id`, `organization_id`, `team_id`, or `workspace_id` columns exist.
- **No SaaS Billing Tables:** Zero `subscriptions`, `plans`, `invoices`, or `payment_methods` tables exist.
- **No Permanent Guest User Accounts:** Zero `users` table exists. Guests are strictly ephemeral visitors.
- **No Raw Biometric Persistence:** Zero guest selfies or selfie storage keys are persisted in the database.
